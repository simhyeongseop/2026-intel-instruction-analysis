# 회의록 안내

이 폴더의 회의록과 발표 초안은 작성 당시의 진행 상황을 보존한 **이력 자료**다. 문서 안의 단계 번호, 버그 개수, 커버리지 수치는 이후 실험으로 바뀌었을 수 있다.

현재 프로젝트의 기준은 다음 문서다.

- [프로젝트 README](../../README.md): 현재 목적, 결론, 실행 방법
- [파이프라인 안내](../PIPELINE.md): 현행 1~13단계와 산출물
- [재심 보고서](../CASE_REVIEW_2026-09-14.md): 2026-09-14 경계 사례 재검토
- [결과의 유효 범위와 버그 판정 기준](../RESULT_VALIDITY_AND_BUG_CRITERIA.md): 판정 규칙과 제한
- [현재 인계 사항](../HANDOFF.md): 구현 상태와 남은 범위

회의록의 과거 수치를 현재 결과로 덮어쓰지 않았다. 과거 결론이 현재 결론과 어떻게 달라졌는지는 [DEVLOG](../DEVLOG.md)와 재심 보고서에서 확인한다.
