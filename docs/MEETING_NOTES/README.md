# 회의록 안내

이 폴더의 회의록과 발표 초안은 작성 당시의 진행 상황을 보존한 **이력 자료**다. 문서 안의 단계 번호, 버그 개수, 커버리지 수치는 이후 실험으로 바뀌었을 수 있다.

## 11회 보고 자료 (2026-09-21 발표, 현재 산출물 기준)

이 네 문서는 이력이 아니라 **현재 기준**이다. 수치는 `scripts/check_report_numbers.py`가
`out/`·`data/db/`에서 재계산해 대조한다.

- [11회 발표자료](11회_발표자료.md): 본문
- [1페이지 요약](11회_발표_요약_1페이지.md): 먼저 보실 요약
- [LSS 시연 가이드](11회_LSS_시연_가이드.md): 라이브 데모 절차와 버전별 관측
- [발표 전 체크리스트](11회_발표_전_체크리스트.md): 정정 이력과 예상 질문

2026-09-16에 만든 준비 자료([11회_보고_준비.md](11회_보고_준비.md)와 `Claude outputs/`의 6개 문서)는
그 시점의 산출물(입력 7,276줄) 기준이다. 9/19·9/20 라운드 이후 수치와 결론이 바뀌었으므로
**발표에는 위 네 문서를 쓴다.** 9/16 자료는 정정 이력으로 남겨 둔다.

현재 프로젝트의 기준은 다음 문서다.

- [프로젝트 README](../../README.md): 현재 목적, 결론, 실행 방법
- [파이프라인 안내](../PIPELINE.md): 현행 1~13단계와 산출물
- [재심 보고서](../CASE_REVIEW_2026-09-14.md): 2026-09-14 경계 사례 재검토
- [결과의 유효 범위와 버그 판정 기준](../RESULT_VALIDITY_AND_BUG_CRITERIA.md): 판정 규칙과 제한
- [현재 인계 사항](../HANDOFF.md): 구현 상태와 남은 범위

회의록의 과거 수치를 현재 결과로 덮어쓰지 않았다. 과거 결론이 현재 결론과 어떻게 달라졌는지는 [DEVLOG](../DEVLOG.md)와 재심 보고서에서 확인한다.
