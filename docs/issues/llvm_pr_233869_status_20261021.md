## 실제 CI 실패와 후속 수정

Linux와 Windows 모두 LLVM 테스트의 실패 항목은
`MC/Disassembler/X86/apx/evex-format.txt` 한 개다.

- Linux: https://github.com/llvm/llvm-project/actions/runs/39442994517/job/118714069723
- Windows: https://github.com/llvm/llvm-project/actions/runs/39442994517/job/118714069500

기존 93행은 다음의 예전 출력을 기대한다.

```text
vscatterpf0dps {k1}, dword ptr [r16 + zmm0]
```

수정한 LLVM의 출력은 의도대로 다음과 같다.

```text
vscatterpf0dps dword ptr [r16 + zmm0] {k1}
```

초기 패치에서 기존 역어셈블 테스트의 기대값 갱신을 누락했다.
Linux 로그 끝의 premerge-advisor 연결 시간 초과는 실패 해설 단계의 추가 문제이며,
테스트 실패 원인과 구분한다.

별도 snapshot `out/avx512pf_ci_followup_20261021/`에서 다음을 로컬 수정했다.

1. 기존 역어셈블 테스트의 기대 마스크 위치를 갱신.
2. `llvm/test/MC/X86/apx/evex-format-intel.s`에서 같은 버그 때문에 주석 처리된
   prefetch 예제를 `dword ptr [r16 + zmm0] {k1}`로 복구.
   기존 기대 바이트 `62 fa 7d 49 c6 2c 00`은 유지한다.

기존 검증 8개와 APX 정상/역어셈블 테스트를 함께 실행해 lit 10/10 통과,
실패·건너뜀 없음. 새 CPU 실행이나 전체 LLVM 테스트는 수행하지 않았다.
